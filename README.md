# วงศธร ฉาบสีทอง — Portfolio (one page)

พอร์ตโฟลิโอหน้าเดียว เขียนด้วย HTML + CSS + JavaScript ล้วน **ไม่มี framework ไม่มี build step**
เปิดไฟล์ `index.html` ได้ทันที (แนะนำให้เปิดผ่าน local server เพื่อให้รูปโหลดครบ)

---

## โครงสร้างไฟล์

```
Profile/
├─ index.html                 ← หน้าเดียวจบ (พอร์ตใหม่)
├─ profile.jpg                ← ★ วางรูปตัวเองตรงนี้ แล้วรูปจะขึ้นอัตโนมัติ
├─ assets/
│  ├─ css/main.css            ← ดีไซน์ซิสเต็ม "engineered dark" + โหมดสว่าง
│  ├─ js/projects.js          ← ข้อมูล 15 โปรเจกต์ + 274 ไฟล์สื่อ (สร้างอัตโนมัติ)
│  ├─ js/main.js              ← ทุกอินเทอร์แอคชันของหน้า
│  ├─ favicon.svg
│  └─ apple-touch-icon.png
├─ media/                     ← รูป/วิดีโอที่บีบแล้ว 1,337 ไฟล์ (77.5 MB)
│  └─ hero/hero-bg.mp4        ← วิดีโอพื้นหลังหน้าแรก
├─ _legacy/                   ← พอร์ตเวอร์ชันเดิมของคุณ สำรองไว้ครบ
└─ _build/                    ← สคริปต์บีบรูป/วิดีโอ + ไฟล์ต้นฉบับวิดีโอพื้นหลัง
```

## ★ วิธีใส่รูปตัวเอง

บันทึกรูปชื่อ **`profile.jpg`** ไว้ในโฟลเดอร์เดียวกับ `index.html`
รีเฟรชหน้าเว็บ รูปจะเข้าไปแทนกล่อง placeholder ในหัวข้อ "เกี่ยวกับผม" เอง
(รองรับ `.jpg` `.jpeg` `.png` `.webp` — แนะนำสัดส่วนแนวตั้ง 4:5 เช่น 1000×1250 px)

ถ้ายังไม่ใส่ ก็ไม่พัง — จะแสดงกล่อง placeholder ที่ออกแบบไว้แล้วแทน

## ฟีเจอร์

| | |
| :-- | :-- |
| **ภาษา** | ไทยเป็นหลัก สลับอังกฤษได้ทุกจุด (ปุ่ม TH/EN บนแถบเมนู) |
| **ธีม** | มืด/สว่าง จำค่าที่เลือกไว้ ผ่านคอนทราสต์ AA ทั้งสองโหมด |
| **พื้นหลังหน้าแรก** | วิดีโอ 3 ช็อตครอสเฟด + เลเยอร์ constellation วาดด้วย canvas |
| **ผลงาน** | กรองตามประเภท + ค้นหาสด + ผูกกับ URL (แชร์ลิงก์ที่กรองไว้ได้) |
| **รายละเอียด** | คลิกการ์ด → drawer แสดงตัวเลข ฟีเจอร์ เทคโนโลยี ซอร์สโค้ด และแกลเลอรีเต็ม |
| **แกลเลอรี** | Lightbox รองรับทั้งรูปและวิดีโอ เลื่อนด้วยลูกศร กด ESC ปิด เต็มจอได้ |
| **ค้นหาเร็ว** | กด `Ctrl+K` (หรือ `⌘K`) เพื่อกระโดดไปส่วนใดก็ได้ หรือเปิดโปรเจกต์ |
| **การเข้าถึง** | WCAG 2.1 AA · axe-core 0 violations · ใช้คีย์บอร์ดได้ครบ · เคารพ reduced-motion |
